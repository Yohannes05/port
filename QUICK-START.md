## 🚀 **How to Use**

### **Step 1: Download the Script**
- **Windows**: Download `book-delivery-setup.bat`
- **Mac/Linux**: Download `book-delivery-setup.sh`

### **Step 2: Run the Script**

**Windows:**
```cmd
# Double-click the file OR run in Command Prompt:
book-delivery-setup.bat
```

**Mac/Linux:**
```bash
# Make it executable and run:
chmod +x book-delivery-setup.sh
./book-delivery-setup.sh
```

### **Step 3: Wait for Magic! ✨**
The script will:
- ✅ Check if you have PHP, Composer, Node.js
- ✅ Create Laravel backend with authentication
- ✅ Create Next.js frontend with TypeScript
- ✅ Install all dependencies
- ✅ Set up database with demo users
- ✅ Create API routes and pages
- ✅ Generate startup scripts
